# acquisition

The human-controlled gate between discovery and the corpus. Discovery cannot authorize acquisition, and
approval to retrieve is not approval to redistribute.

| Folder | Contents |
| --- | --- |
| `candidates/` | Candidate records with stable artifact IDs |
| `approved/` | Approval manifest naming artifacts cleared for retrieval |
| `rejected/` | Rejected candidates with a recorded reason |
| `logs/` | Acquisition run logs |
