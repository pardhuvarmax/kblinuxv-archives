# acquisition/candidates

`candidates.json`: the 709 reproduction candidates with a triage level (`ready`, `needs-review`, `needs-resolution`) and flags, produced by `tools/acquisition/extract_candidates.py`. `proposed-first-batch.md` is a suggestion only; nothing is approved until you add IDs to `acquisition/approved/approved-artifacts.yaml`. Triage is heuristic and name-based, not a code review.
