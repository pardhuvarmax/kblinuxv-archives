# Contributing

- Propose artifacts or corrections through the issue templates.
- Dataset changes arrive as pull requests; automation PRs come from `automation/*` branches.
- Provenance (source URL, repository, commit) and license status are required for every artifact.
- Never submit unsolicited exploit code without its original license and attribution.
- Run `make check` (gofmt, vet, tests) before opening a PR.
- Do not execute archived PoCs outside an isolated, disposable lab.
