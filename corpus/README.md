# corpus

The curated source corpus: actual PoC and reproducer files, grouped by category, where redistribution is
permitted. Original files are preserved unmodified with their original attribution and license; the archive
does not relicense them. Where the license is unknown or restrictive, only metadata and the source reference
are kept.

Layout: `corpus/<category>/<CVE>/<artifact-id>/<file>`. Each CVE folder has a README with the vulnerability's
NVD and registry data and its artifacts; each artifact folder has a README with its pinned source, license and hash.
They are generated by `tools/processing/generate_readmes.py` from `metadata/`.

**Nothing here is executed, compiled or run by KB-LVA automation.** Do not run these files outside an
isolated, disposable lab.
